📘 How the Route Planner Works

📍
Haversine Distance

Calculates straight-line distance between two GPS coordinates accounting for Earth's curvature. Accurate for distances under ~1,000 km.

🤖
Nearest Neighbor Algorithm

From the current position, always go to the closest unvisited delivery. Simple, fast, and gives good results for small fleets.

🗺️
OpenStreetMap + Leaflet

Free, open-source interactive maps. No API key required. Markers show delivery locations; dashed line shows the planned route.
